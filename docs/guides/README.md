# Guides

Task-shaped help for running the extension host:

| Guide | Use it when |
|---|---|
| [Operate](operate.md) | You're running the image and reading health, metrics, and logs |
| [Troubleshoot](troubleshoot.md) | Nothing is being collected, or claims keep failing |
| [Collector placement](seed.md) | You need the collector binary where the host can run it (there is no seed command) |
| [Release](release.md) | You're publishing an image from a version tag |

For the ideas behind these guides, see
[concepts](../concepts/README.md). For every flag and
variable, see [reference](../reference/README.md).
